# César Construcción 🛠️

Repositorio de trabajo para organizar proyectos, remodelaciones y trabajos de construcción de **César González**.

## Objetivo

Centralizar información útil para preparar, documentar y dar seguimiento a trabajos de obra, incluyendo:

- Presupuestos y cotizaciones.
- Cubicaciones y cálculo de materiales.
- Registro de trabajos realizados.
- Boletas, gastos y mano de obra.
- Ideas y bocetos para clientes.
- Proyectos de remodelación.
- Material para contenido de redes sociales.

## Áreas de trabajo

### Presupuestos
Plantillas, valores de mano de obra y referencias para preparar cotizaciones de forma más rápida y ordenada.

### Cubicaciones
Cálculos de hormigón, techumbres, revestimientos, tabiquería y otros materiales de construcción.

### Proyectos
Información y seguimiento de obras como techumbres, canaletas, radieres, hornos pizzeros, walking closets y remodelaciones en general.

### Clientes y trabajos
Documentación de cada trabajo, materiales utilizados, costos, avances y cierre de obra.

### Ideas y diseños
Bocetos, propuestas y referencias para presentar alternativas de construcción y remodelación a clientes.

## Organización inicial

El repositorio se irá organizando en carpetas según el tipo de información y proyecto, manteniendo los documentos fáciles de encontrar y actualizar.
